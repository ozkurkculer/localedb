# v1.0.1

**Release Date:** 2026-09-28
**Previous Version:** v1.0.0
**Total Commits:** 4

---

A follow-up to 1.0: the npm packages now have a place on the home page and in the menu, the footer is simplified, search engines index every translated page, and a few rough edges are fixed.

---

## ✨ Features

### 📦 npm packages on the home page ([PackagesSection](src/components/home/packages-section.tsx))

The packages were only described deep in /docs. The home page now has a section below the feature cards:

- **Left:** `@localedb/core · @localedb/cli` label, title, short description, `npm install @localedb/core`, and two buttons: **Documentation** (to `/docs#packages`) and **npm** (to npmjs.com).
- **Right:** a short `getCountry("TR")` example and a one-line CLI command, always left-to-right, also in Arabic.
- All text comes from the existing `docs.packages` keys, so the section is translated in every locale.

### 🧭 "npm & CLI" in the Project menu ([navigation.ts](src/config/navigation.ts))

New entry in the desktop and mobile Project menus, linking to `/docs#packages`. The label reuses `docs.toc.packages`.

## 🐛 Bug Fixes

### Search engine indexing (canonical and hreflang)

Shipped with the 1.0.0 commit, documented here.

- **Canonical URLs had no locale prefix.** Every translation (for example `/es/updates`) pointed its canonical at the English page, so Google treated translations as duplicates and left them unindexed. Country and currency detail pages had no canonical at all and inherited the home page's.
- New [`localeAlternates()`](src/lib/seo.ts) gives every page its own canonical plus hreflang links for all 11 locales and `x-default`. The layout no longer sets a canonical.
- **Redirects** ([next.config.ts](next.config.ts)) for URLs Google still crawls: `/api` and `/<locale>/api` go to the docs (temporary, until the public API exists); `/countries/UNK` goes to `/countries/XK` (Kosovo).
- **`/og-image`** is no longer rewritten by the locale middleware, and no longer fails reading its background image (Node's fetch cannot read `file://` URLs).

### Hero date format

The home hero's data boxes read `datePatterns.short`, which holds CLDR skeletons since the move to CLDR (`yMMd`). They now show the real pattern from `dateFormats.short` (`d.MM.y`).

## 💅 UI / UX Polish

- **Footer:** the brand column now carries a single descriptive paragraph (what LocaleDB covers, where the data comes from, how to use it), translated in all 11 languages. The creator name links to [ozkurkculer.com](https://ozkurkculer.com).
- **Export builder:** removed the "Setup progress" bar; the ✓ marks on each step already show progress.
