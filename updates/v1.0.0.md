# v1.0.0

**Release Date:** 2026-09-28
**Previous Version:** v0.6.1
**Total Commits:** 22

---

LocaleDB 1.0 is the first stable release. The dataset is now built entirely from openly licensed sources, it ships as two npm packages (`@localedb/core` and `@localedb/cli`), and the home page has a new look.

---

## ✨ Features

### 📦 npm packages: `@localedb/core` and `@localedb/cli`

The whole dataset is now available offline, as a typed npm package and a command-line tool. The repository is a pnpm workspace; shared types and export helpers moved from `src/` into [`packages/core`](packages/core), and the web app imports them from there.

- **`@localedb/core`** ([packages/core](packages/core)): the dataset bundled as minified JSON, plus a synchronous, cached Node API: `getCountry`, `getCurrency`, `getLanguage`, `getAirport`, `list*`, `searchCountries`, `getMeta` and `createLocaleDB(dir)`. Accepts ISO alpha-2 or alpha-3 codes, case-insensitive. ESM + CJS + type declarations.
- **`@localedb/core/browser`**: environment-agnostic types and helpers (`pickFields`, CSV serialisation) for browsers and bundlers, alongside importable `data/*.json` records.
- **`@localedb/cli`** ([packages/cli](packages/cli)): `localedb get`, `export` (JSON, CSV, TypeScript), `list`, `search`, `init` (interactive `localedb.config.json`) and `sync` (regenerate files from the config; `--check` for CI). `--fields` selects nested paths such as `currency.symbol`.
- **[`NOTICE`](packages/core/NOTICE)** lists every bundled data source and its license.
- **CI**: [`packages-ci.yml`](.github/workflows/packages-ci.yml) typechecks, tests and builds both packages; [`packages-publish.yml`](.github/workflows/packages-publish.yml) builds the dataset from upstream, bundles it and publishes both packages with npm provenance (manual trigger, dry-run by default).

### 🗂️ Open data pipeline: SimpleLocalize replaced

Every field that came from SimpleLocalize is now built from openly licensed sources, each with its own loader in [`scripts/sources/`](scripts/sources):

- **Unicode CLDR** ([cldr.ts](scripts/sources/cldr.ts)): country names, date/time and number formats, currency formats, continents (M49 tree), population fallback, FIPS codes.
- **IANA tz database** ([tz.ts](scripts/sources/tz.ts)): time zones per country, with the capital's zone as the primary one.
- **Google libaddressinput** ([address.ts](scripts/sources/address.ts)): address formats, postal code patterns and examples.
- **Wikidata** ([wikidata.ts](scripts/sources/wikidata.ts)): FIFA codes (from national federations), vehicle registration codes, ITU, UIC, MID and MCC codes, driving side and capital coordinates.
- **ourworldincode/currency** ([currency-units.ts](scripts/sources/currency-units.ts)): currency subunit names and subunits per unit, with Wikidata as a fallback.
- SimpleLocalize and the ICU data (derived from CLDR) were removed. The STANAG field was dropped, as no open source carries it.
- Current dataset: **250 countries, 152 currencies, 119 languages, 9,400+ airports**.

### 🎨 New home hero

- **Dithered background** ([dither-background.tsx](src/components/home/dither-background.tsx)): a WebGL dither effect across the whole hero.
- **Decoding locale data boxes** ([locale-data-boxes.tsx](src/components/home/locale-data-boxes.tsx)): boxes with real country data (codes, currencies, formats) that decode in and out over the dither, in Latin characters, digits and symbols only.
- **New title**: "The World's Localization Encyclopedia", with the highlighted phrase on its own line, for a broader audience than developers alone.

### ⚖️ Privacy and Terms pages

New [`/privacy`](src/app/[locale]/privacy/page.tsx) and [`/terms`](src/app/[locale]/terms/page.tsx) pages built on a shared [`LegalDocument`](src/components/legal/legal-document.tsx) component, linked from the footer and added to the sitemap. Translated into all 11 languages.

## 🐛 Bug Fixes

- **Dither disappeared after a locale switch.** The new WebGL program never received its resolution uniform; the size is now tracked per effect run.
- **Countries grid glitch.** Switching continents made cards fly in from their old grid positions (bottom right). The grid now fades out as a whole and fades back in with a short stagger capped at the first 16 cards; reduced motion is respected.
- **Corrupted `_meta.json`.** `build-data` called `build()` twice, so two builds wrote the same files concurrently. It now runs once and exits with an error code on failure.
- **Data pipeline on a fresh checkout.** Downloads create their target folder, the GitHub API call is authenticated with `GITHUB_TOKEN` in CI, and Wikidata queries retry on network errors as well as on 429/5xx.
- **Data fixes** from the source migration: missing African continents (multi-parent M49 tree), FIPS codes equal to alpha-2, zero populations, postal format order and a Belarus example that failed its own regex.
- **README logo** now switches between light and dark variants, so it renders fully on GitHub's light theme.
