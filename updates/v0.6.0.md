## ✨ Features

### 📦 Data Export Interface (`/export`)

Interactive 4-step wizard that lets users build custom locale-data exports without writing scrapers.

- **Step 1 — Dataset picker.** Choose one of: Countries, Currencies, Languages, Airports. Selected card highlights in dataset color (blue / amber / emerald / rose); unselected stay muted gray with hover scale-up + color reveal.
- **Step 2 — Entity selector.** Searchable, paginated checkbox grid (60 per page). "Select all filtered" / "Clear" helpers. Live `aria-live` selected-count indicator.
- **Step 3 — Field tree.** Collapsible field selector built from the `CountryLocaleData` schema (basics, codes, currency, dateTime, numberFormat, phone, addressFormat, airports, locale). Per-group indeterminate state. Default selections optimized for typical exports.
- **Step 4 — Format & download.** Pick JSON (pretty), JSON (minified), CSV (RFC 4180, flattened with dot-notation keys), or ZIP (one JSON file per entity).
- **Live preview.** Renders the first selected entity in chosen format:
  - JSON view: syntax-highlighted (keys=sky, strings=emerald, numbers=amber, booleans=rose, null=muted italic) — no external highlighter dep.
  - CSV view: Excel-style table with A/B/C column headers, sticky row + column, hover row highlight, monospace.
  - ZIP view: info card explaining contents.
- **Download flow.** `Blob` + `URL.createObjectURL` — no `file-saver` dependency.
- **Server-side serialization.** All data loading + heavy serialization in `/api/export` route handler (Node runtime, `maxDuration: 30`). Client wizard only holds selections in `useState`, keeping bundle thin.
- **i18n.** Full `export.*` namespace across all 11 supported locales (en, tr, zh, hi, es, fr, ar, bn, pt, ru, ja). RTL-safe.
- **Accessibility.** ARIA-labeled radio groups, focus-visible rings, keyboard nav through all 4 steps, `aria-live` regions for selection counts, progress bar with `aria-valuenow`.
- **Motion.** Stepper progress bar uses Framer Motion `layout`; downloaded button briefly flashes check icon (mirrors `CopyButton` pattern); respects `prefers-reduced-motion` globally.

### 🎨 New UI primitive

- **`<Checkbox>`** ([`src/components/ui/checkbox.tsx`](src/components/ui/checkbox.tsx)) — shadcn-style Radix wrapper with flat indigo fill on check/indeterminate, fixed `border-zinc-400` (light) / `border-zinc-600` (dark), focus ring, indeterminate dash icon. Reusable across the project.

### 🧰 New library helpers

- [`src/lib/export/field-schema.ts`](src/lib/export/field-schema.ts) — declarative field tree per dataset + `collectAllPaths` / `collectDefaultPaths` walkers.
- [`src/lib/export/pick.ts`](src/lib/export/pick.ts) — client-safe `pickFields` deep selector (no Node deps).
- [`src/lib/export/csv.ts`](src/lib/export/csv.ts) — client-safe CSV serializer (RFC 4180 escape, dot-flatten arrays/objects).
- [`src/lib/export/serialize.ts`](src/lib/export/serialize.ts) — server-side: `toJson`, `toZip` (via `adm-zip`), `getFilename`, `getMimeType`; re-exports `pickFields` + `toCsv`.

## 💅 UI / UX Polish

### Navbar

- Removed visible borders from Data / Project dropdown triggers; explicit `bg-transparent` + `border-0` so they no longer pick up the browser UA `<button>` default fill in light mode.
- **Export** promoted from a `data` dropdown item to a top-level standalone nav link, restyled to match Data / Project (same height, padding, `hover:bg-accent`, no gradient), reordered last (Data → Project → Export).
- Mobile nav mirrors the same ordering and drops the indigo icon tint for visual consistency.

### CMD+K command palette

- Replaced default bare `XIcon` close (with `opacity-70 hover:opacity-100`) with a modern muted chip: `size-7 rounded-md bg-muted/60 hover:bg-muted active:scale-95 focus-visible:ring-2`. Sets `showCloseButton={false}` on the underlying `DialogContent` so this override is scoped to `CommandDialog`.
- Input wrapper given `pr-12` so text never slides under the close button.
- Fixed Firefox-specific focus border on `CommandInput` (added `border-0 outline-none focus:outline-none focus-visible:outline-none focus-visible:ring-0`) and on `AccordionTrigger` (replaced UA dotted outline with subtle `focus-visible:ring`).

### Dataset picker cards (export wizard)

- Border removed.
- Unselected cards: muted gray bg (`bg-zinc-200/70` light, `bg-muted/30` dark) with `text-muted-foreground` icon.
- Hover (unselected): `scale-[1.03]` + dataset-color gradient + icon flips to dataset color via static `group-hover:text-*` (Tailwind JIT-safe).
- Selected: dataset-color gradient + `ring-2 ring-offset-2` in the dataset hue, no border.
- Currency icon swapped `CircleDollarSign` → `Coins` to match the homepage feature card.
